# NMAMIT – Attendance Regulations

## Batch-specific warning
Attendance rules are regulatory information and can vary by scheme or batch.

The official examination portal contains an Attendance & Marks section. The exact final rule for the 2025–2029 CSE/NDU batch should be answered from the applicable current regulation or attendance document.

An older NDU 2023–2027 CSE regulation is available online, but it should not be presented as the current 2025–2029 rule without verification.

## RAG behavior
If the current 2025–2029 attendance rule is not present in the indexed knowledge base, the assistant should state that the applicable current rule could not be verified and direct the student to the official source.
