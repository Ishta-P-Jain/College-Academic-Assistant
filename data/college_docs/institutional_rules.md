# NMAMIT – Institutional Rules and Code of Conduct

## Official rules pages
NMAMIT provides an official Rules & Regulations page and a separate Code of Conduct page.

The Code of Conduct page provides dedicated sections for:
- Administrators
- Teachers
- Students

The NMAMIT website also provides links for anti-ragging measures, grievance redressal, gender sensitization, SC/ST committee support, mentoring and counselling.

## RAG rule
For exact disciplinary or conduct questions, retrieve the relevant official rule or code document rather than generating a rule from general knowledge.
